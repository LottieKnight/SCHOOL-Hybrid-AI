# SCHOOL Compounding Roadmap

## Planning Rule

Prioritize assets and features that compound advantage:

- shared data models
- reusable UI primitives
- product language consistency
- assessment loops
- planner-memory integration
- progress proof

Avoid shipping isolated features that add maintenance without improving the operating system.

## Now

### 1. Command Center Upgrade

- strengthen `/dashboard` as the execution surface
- make past papers, due items, mastery review, and planner actions explicit
- keep mobile scanning quality high

### 2. Past-Paper Reliability

- fix strict TS/build blockers in clustered past-papers routes
- validate browse flow and viewer flow
- preserve "past-paper supremacy" in IA and copy

### 3. Learner Memory Exposure

- use humane mastery language
- connect memory summaries to next actions
- push review cues into command center and AI coach flows

### 4. Planner Execution Quality

- keep deadlines and academic period context visible
- strengthen upload/sync resilience before adding planner novelty

### 5. Queue Operations Reliability

- complete low-risk lesson-generation queue lifecycle controls
- keep admin queue operational for content throughput

## Next

### 1. Proof Of Progress Layer

- weekly study report
- mastery movement summary
- past-paper performance trend
- tutor-ready progress summary

### 2. Assessment-to-Intervention Flow

- weakness detected from practice
- AI remediation plan
- planner block creation
- tutor escalation

### 3. Resource Intelligence

- rank textbooks/resources by current relevance
- explain recommendation reason
- connect recommendations to weak areas and upcoming assessments

## Later

### 1. Outcome-Driven Tutor Marketplace

- weakness-to-tutor matching
- session outcome tracking
- post-session improvement evidence

### 2. Deeper Social Learning

- stronger academic room workflows
- accepted-answer prominence
- revision-group mechanics tied to courses or exams

## Explicit Non-Goals For This Phase

- broad new social feature sets
- decorative redesign churn
- multiple overlapping study surfaces
- speculative AI features without workflow grounding

## Review Gate For New Work

Before approving a feature, ask:

1. Does this improve a core student decision?
2. Does it strengthen assessment, planning, memory, or support?
3. Does it create reusable leverage?
4. Will it still matter six months from now?
5. Is it better than improving command center, past papers, planner, or proof of progress?
